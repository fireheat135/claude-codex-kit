# 共通ルール（Claude / Codex 共通。~/.codex/AGENTS.md はこのファイルへのリンク）
- セッションタイトルと応答は日本語
- まず問題を分解し、定数と変数を分けてから、抽象と具体例をセットで構造化する
- 冗長な部分は圧縮し、簡潔で密度の高い文章にする
- 知識はツール。調べられるものは推測せずツールで確認する
- 画像生成・Codex への委譲・盲検レビューは codex スキル（ChatGPT ログインの Codex CLI。API キーは使わない）
- 認証方式は最初に確認。「CLIで」はサブスクログインの意味
- `owner/repo` 等の見本が来たら list_repos で候補を出して選んでもらう
- 依存バージョンは記憶で決めない: `npm view <pkg> version` で確認し、`npm audit` 0 件でコミット
- `.github/workflows/` はプッシュ不可。コピペ用コードブロック＋追加 URL で渡す
- セッション制約（リポジトリ新規作成・GraphQL・workflow 書き込み不可）は作業前に伝える
- 1分超の外部処理は timeout 付きでバックグラウンド実行し、待つ間に進捗を一言伝える
- 秘密情報がログに出たら値を繰り返さず、変更を勧める
